01

Overview

Two simulated manipulators move a cube between platforms through an intermediate handover. The challenge is coordinating motion within a shared workspace.

02

Requirements & constraints

The handover pose must be reachable by both arms. Motion and object-transfer sequencing must be coordinated.

03

My contribution

This is a group project. The implementation includes workspace analysis, inverse kinematics, trajectory generation and handover coordination.

04

Approach & decisions

The repository includes an OMPL RRT-Connect planner and a task state machine. The inspected version uses timed transitions and a kinematic attachment for the cube.

05

Results & validation

The simulation implementation is available in the maho_matpao branch. The project is presented as a simulation study, without a claim of physical deployment.

06

Limitations & next steps

Kinematic attachment does not test contact-based grasp failures. The code also depends on scene assets and a generated handover configuration; timing and placement metrics require the final run records.
