# Matteo Paolini — portfolio

Static site for GitHub Pages, generated by `build.py`. The visual style comes from `verified-base.html` (tokens, type, layout) plus `additions.css`; `styles.css` and every `index.html` are generated, so edit the sources below and rebuild.

```sh
python3 build.py          # rebuild every page
python3 -m http.server    # preview at http://localhost:8000
```

## Where things live

| What | File |
|---|---|
| Hero, about, availability, toolkit, contact | `site.json` |
| A project | `projects/<slug>/project.json` |
| Project figures | `assets/` or `projects/<slug>/media/` |
| CV | `cv/cv.html` → print to PDF as `assets/Matteo-Paolini-CV.pdf` (A4, no margins, background graphics on) |
| Social preview image | `assets/og-card.png` |

## Project fields

- `tier`: `featured` (card on home and Work), `archive` (one line under *More projects*) or `hidden`.
- `page`: `false` for archive entries without a case study; their old URL redirects to the list.
- `summary`, `role`, `metrics` (`[value, label]`, the first appears on the card), `tools`, `tldr`, `facts`.
- `cover` (card thumbnail and social image) and optional `hero_media` (top of the case study); add `"fit": "contain"` for drawings and diagrams.
- `sections`: each has `id`, `title` and `body`. A body item is a paragraph string, `{"list": [...]}`, `{"note": "..."}`, `{"log": [[date, text], ...]}` or a media block (`image`, `gallery`, `video`, `youtube`, `map`, `svg`).
- `links` (`[label, url]`) and an optional `links_note`.

## Updating the DREAM page

Add a line at the top of the `Research log` section in `projects/dream/project.json`, update `Status` in `facts`, then rebuild. Check with the RMA supervisor before publishing new figures or results.
